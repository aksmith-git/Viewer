## Description
Viewer opens almost any file on your iPhone and iPad — and shows it the way it's meant to look.

WEB PAGES THAT ACTUALLY RUN
Most previews show HTML with JavaScript turned off. Viewer runs it: scripts, modules, canvas, animations and local data all work. Open a whole folder or a zip of a website and its styles, scripts and images load too.

TOOLS FOR THE CURIOUS
• View the page source, with syntax colours
• A JavaScript console with errors, warnings and logs — and a prompt to run your own code
• Find on page
• Request the desktop or mobile version
• Save as PDF or print

CODE, MARKDOWN, JSON AND CSV
• Syntax colours and line numbers for nearly 200 languages
• Markdown rendered like a great README, with tables, task lists and code blocks
• JSON as a tree you can expand, collapse and copy from
• CSV and TSV as a real table with a pinned header row

DOCUMENTS AND MEDIA
• PDFs with page thumbnails, search and password support
• Word, Excel, PowerPoint, Pages, Numbers, Keynote and RTF
• Images with pinch and double-tap zoom
• Video, audio and 3D models
• A clean text view for anything else

MADE FOR iPHONE AND iPAD
• Open files from the Files app, iCloud Drive, USB drives and other apps' share sheets
• Recent files and pins, so what you need is one tap away
• Sidebar layout on iPad, keyboard shortcut ⌘O to browse
• Light and dark mode

PRIVATE BY DESIGN
No accounts. No tracking. No data collected. Your files never leave your device.

## What to test / App Review notes
Viewer opens files the user chooses; it has no login. To try the main feature:
1. In Safari on the device, download https://aksmith-git.github.io/Viewer/samples/Viewer-Sample-Site.zip
2. Open Viewer → Browse → Downloads → Viewer-Sample-Site.zip → Website → Open Website.
   The page runs JavaScript modules, fetches local JSON and animates a canvas.
3. Docs/README.md (Markdown), Data/app-config.json (JSON tree), Data/cities.csv (table) show the other viewers.
Links to websites inside opened pages intentionally open in Safari; Viewer is not a web browser.
