# Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free iPhone/iPad App Store app that opens almost any file and runs HTML with JavaScript.

**Architecture:** SwiftUI app generated with xcodegen. Pure, unit-tested core (`FileKind`, `RecentsStore`, `ZipExtractor`, `NavigationPolicy`, `CSVParser`, `JSONNode`, `Languages`) under `Viewer/Core`; thin SwiftUI/UIKit viewers under `Viewer/UI`; bundled JS (highlight.js, marked) under `Viewer/Resources/web`. A `DocumentView` routes a URL to a viewer by `FileKind`.

**Tech Stack:** Swift 6 / SwiftUI, WKWebView, QuickLook, UniformTypeIdentifiers, ZIPFoundation (SPM), highlight.js, marked, XCTest, xcodegen.

**Spec:** `docs/superpowers/specs/2026-11-05-viewer-design.md`

## Global Constraints

- iOS/iPadOS 17.0+, universal (iPhone + iPad), bundle ID `com.adriansmith.viewer`, team `77STY5BM38`, display name `Viewer`.
- No analytics, ads, accounts or network calls by the app itself; `ITSAppUsesNonExemptEncryption = NO`; privacy manifest declares only required-reason APIs actually used.
- Top-level `http(s)`/`mailto`/`tel` navigations leave the app (age rating 4+).
- Size fallbacks: JSON > 10 MB → code view; CSV > 50 000 rows → first 50 000 + notice; code > 2 MB → plain text; text > 5 MB → first 5 MB + notice.
- Recents: max 50, security-scoped bookmarks, pins.
- Zip extraction into `Caches/Extracted/<hash>/`; entries escaping the root are rejected.
- Test command: `xcodebuild test -project Viewer.xcodeproj -scheme Viewer -destination 'platform=iOS Simulator,name=iPhone 18 Pro'`.

## Review Focus

- Paths with spaces, unicode or `#` → file loads and relative CSS/JS resolve (Task 4 `testInsideRootWithSpaces`, Task 1 `testUnicodePath`).
- `.HTML` uppercase or an extensionless file that starts with `<!doctype html` → web view (Task 1 `testUppercaseExtension`, `testSniffHTML`).
- A 100 MB log file → opens quickly, truncated with a notice, no memory spike (Task 5 `testTextTruncatedOver5MB`).
- A recent whose file was deleted or moved → greyed "Not found", tapping doesn't crash (Task 2 `testMissingFileFlagged`).
- Dark mode → code, Markdown and JSON stay readable (Task 7 simulator screenshots in dark mode).
